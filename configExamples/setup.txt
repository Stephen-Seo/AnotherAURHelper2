The host and container must be using systemd-networkd.
The host must be using nftables.

Set up "50-aurbuild.network" in the host's /etc/systemd/network/ directory.

Set up "80-container-host0.network" in the container's /etc/systemd/network/ directory.

Use forwarding options in "nftables_forwarding_allow.conf" in the host's /etc/nftables.conf file.

Run the container once, and enable systemd-networkd with "systemctl enable systemd-networkd".

Restart the container, run "systemctl daemon-reload ; systemctl restart systemd-networkd" on the host.


For customization (like changing the ip address of container/host), edit the "*.network" files.
